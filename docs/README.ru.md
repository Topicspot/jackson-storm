# jackson-storm

[English](../README.md) · **Русский**

Лендинг со скролл-ревилом: пользователь крутит страницу, страница перематывает видео
кадр за кадром, и машина собирается по деталям — тот же приём, что у Porsche и Apple
на страницах продуктов. Фан-концепт на кадрах трейлера «Тачки 3».

![Первый экран](screenshot-hero.webp)

## Как открыть

- GitHub Pages: `https://topicspot.github.io/jackson-storm/` — включается один раз в Settings → Pages
  (либо *Deploy from a branch* → `main` → `/`, либо источник *GitHub Actions*, workflow уже в репо).
- Локально: просто открыть `index.html` в браузере. Ни сборки, ни зависимостей, ни сервера.

## Как это устроено

Видео никогда не проигрывается. Скролл внутри высокой sticky-секции пересчитывается в
`video.currentTime`, поэтому кадр следует за полосой прокрутки:

```
прогресс = (scrollY - верх сцены) / (высота сцены - высота экрана)
video.currentTime = прогресс * длительность
```

Две детали, без которых это не работает на практике:

- **Сглаживание.** Значение прогресса догоняет цель внутри `requestAnimationFrame`, иначе
  перемотка на тачпаде выглядит рывками.
- **Прайминг для iOS.** Safari не рисует кадры перемотки, пока видео хотя бы раз не запускали,
  поэтому по первому касанию страница делает `play()` и сразу `pause()`.

Восемь подписей привязаны к порогам прогресса (колесо, кромки, крыло, кокпит, разряд,
номер 20, выхлоп, полный образ) и появляются ровно тогда, когда в кадре нужная деталь.

## Структура

```
index.html                  русская версия: разметка, стили и логика скролла
en/index.html               английская версия, те же ассеты, переключатель в шапке
assets/storm-reveal.mp4     1920x1080, 20 fps, 21.9 с, ключевой кадр каждые 10 кадров
assets/hero.webp            кадр для первого экрана, 1920 px
assets/detail-0{1,2,3}.webp кадры для галереи, 1400 px
scripts/build-assets.sh     пересобирает все ассеты из исходного видео
.github/workflows/pages.yml автодеплой на Pages при каждом пуше в main
```

## Пересборка ассетов

Видео готовится под перемотку, а не под просмотр: чёрные стыки между планами трейлера
вырезаны, картинка отгрейжена и подшарплена, интервал ключевых кадров короткий.

```bash
scripts/build-assets.sh путь/к/исходнику.mp4
```

Главное в настройках кодирования: `-g 10` (короткий GOP — быстрая перемотка), `fps=20`
(таймлайн крутит пользователь, лишние кадры только весят), `-crf 22`, грейдинг
(`eq` + `unsharp`) запечён в само видео, а не накручен CSS-фильтром — иначе браузер
вытягивает шум компрессии, и `+faststart` для перемотки до полной загрузки файла.

## Правовая оговорка

Фан-концепт, некоммерческая демонстрация. Джексон Шторм и все кадры в `assets/` взяты из
трейлера «Тачки 3» и принадлежат Disney·Pixar. Код страницы опубликован под лицензией MIT
(файл `LICENSE`), на медиафайлы она не распространяется — они приложены только для личного
использования и портфолио.
